02 · Open source desktop

Document Studio

A free, ad-free, offline PDF workspace for Windows, macOS, and Linux (Flutter) — the full toolkit people expect from heavy commercial suites, without the cloud tax: organize / merge / split / extract / insert, crop & resize, compress, watermark, encrypt with real permissions, redact, repair, metadata, batch jobs, fill forms, visual signatures & stamps, certificate / digital sign, markup (text, highlights, shapes, comments, links), compare PDFs, local Tesseract OCR, and LibreOffice Office→PDF on desktop. Engines are bundled locally (qpdf, Tesseract, LibreOffice, signing helpers) — see the product site.

Why it feels faster than Adobe Acrobat-class workflows: there is no account gate, no upload round-trip, and no remote “convert in the cloud” queue. Jobs run against files on disk through native local binaries with progress/cancel where supported — so latency is your machine, not a browser tab waiting on someone else’s servers. Acrobat and similar suites are powerful, but they’re also heavy subscription products optimized around cloud identity; Document Studio is optimized around local pipelines. Same job categories (organize, protect, sign, edit, OCR, convert) — different default: privacy-first and offline.

Why open source: PDF tools that touch contracts, IDs, and research papers shouldn’t be black boxes. Opening the code lets others audit engines, fork for campuses / labs, and trust that “offline” isn’t a marketing slide. Free forever — no ads, no account, no Document Studio backend that ever sees your files.

03 · Agentic analytics

Optinqo · AI analytics (v03)

Separate from GeoPeriX: an MCP-based agentic data analyst under optinqo. Private v03_frontend (ai-analytics-frontend v0.3) pairs with a v03 backend. Users chat in natural language; the agent selects MCP tools for EDA, time-series, RCA investigations, and QCN / QPN analysis modes. Data connectors cover file uploads and Google Sheets; the UI renders charts, tables, math, and code inline.

Design principle: the LLM plans and interprets — heavy computation stays in deterministic server tools so numbers stay auditable. That’s the difference between a chat wrapper and a real analytics agent. (Research / simulation work on GeoPeriX is a different product line.)

04 · Scientific computing

GeoPeriX

High-performance peridynamics framework for geomechanics research and engineering (geoperix.readthedocs.io). Nonlocal continuum mechanics via integral equations — naturally suited to fracture, damage, and progressive failure without remeshing. Optimized C++17 core with PyGeoPeriX (pybind11): 2D/3D crack growth, multi-fracture interaction, linear elastic / kinematic hardening / Drucker-Prager materials, chunked HDF5 time-series, ParaView plugin + Excel export. Apache-2.0 ecosystem docs.

My contributions sit on optimization and engineering workflows — making simulation loops tighter, tooling saner, and research code paths usable under deadline — not marketing the engine as a consumer app.

05 · Open source local-first

OpenCanvasX

Free, open-source design studio (Apache-2.0) for graphics, illustrations, presentations, documents, diagrams, animation, and video — without mandatory cloud, accounts, or subscriptions. Architecture: Flutter desktop shell, Dart packages, Rust native core via flutter_rust_bridge, plus protocol docs for optional peer collaboration. Target surface includes powerful design tools, local AI / BYOK, plugins, templates, and offline editing. Currently Phase 0 (scaffolding, CI, empty desktop shell) — the product thesis is already locked.

Why open source: creative tools that lock files into proprietary clouds train users to rent their own work. OpenCanvasX is open so the document model, plugins, and local-AI paths stay inspectable and forkable — a studio you can own, extend, and run forever offline. Same philosophy as Document Studio: capability without captivity.

Interests

Where I’m spending intellectual energy — research threads and engineering bets.

AI agents & tool-using systems

I’m researching how agentic systems plan, call tools, maintain memory, and recover from failure — from Optinqo’s MCP analytics agent (EDA / RCA / time-series tool loops) to WhatsApp RAG bots that answer real campus queries. That includes multi-step workflows, evaluation harnesses, retrieval / grounding, and the decisive production pieces: timeouts, retries, permission boundaries, and observability when an agent acts on real software.

Optimization & numerical workloads

From GeoPeriX-style simulation loops to everyday backend latency — profiling hot paths, better data layouts, batching, caching, and knowing when to trade exactness for speed. I like problems where algorithms and systems meet and the code has to finish on deadline.

Platform & systems design

Through Sovaria: clear contracts, gateway semantics, execution isolation, SDK ergonomics, and orchestration that doesn’t punish small teams. APIs that age well and CLIs people actually keep in their muscle memory.

Local-first & open tooling

Document Studio and OpenCanvasX exist because I refuse the default that “serious software” must mean subscriptions and cloud uploads. I’m interested in offline pipelines, local AI / BYOK, honest packaging, and open-sourcing the parts users should be able to audit — especially when the files are contracts, IDs, or creative work that shouldn’t leave the machine.

Applied ML in education products

Sprix and Wayspire keep me close to adaptive learning loops, curriculum tooling, and the systems behind tutors and students — models and product surfaces that hold up in messy reality.
